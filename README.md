# 体重日记（Weight Diary）

一款专注“每日体重 + 七时段平行数据”的 Android 原生应用。一天最多记录 7 次体重（三餐前 / 餐后 + 睡前），以**每日均值**为主线，提供趋势曲线、七时段对比、日内波动、餐前餐后差值等分析。

- 纯 Java 实现，无 AndroidX、无第三方依赖
- 所有图表均为 Canvas 自绘
- 数据只保存在本机，不联网、不需要任何权限
- `minSdk 26`（Android 8.0+），`targetSdk 35`
- 另提供 **网页版（PWA）**，可直接在 iPhone 上使用

## 网页版（iPhone / PWA）

- 地址：**https://yqfand.github.io/weight-diary-android/iosweight/**
- iPhone 使用：Safari 打开上面的地址 → 分享 → **添加到主屏幕**，即可像 App 一样全屏使用，支持离线
- 功能与安卓版一致：每日七次、时段选择、日均趋势、七时段平行折线、分析、JSON 备份
- 数据保存在浏览器本地（localStorage），与安卓版共用同一 JSON 格式，可互相导入
- 源码位于 `iosweight/`；GitHub Pages 从 `main` 分支根目录发布，仓库根 `index.html` 会自动跳转到网页版

## 功能特性

### 记录

- 一天 7 个固定时段，序号 1–7，**第 1 次即早餐前**，第 7 次为睡前
- 录入弹窗可自由选择“第几次”，不必按顺序、不必每天都记满 7 次
- 主按钮自动建议“上一次记录之后的下一次”；若跳过某一餐，也不会强行补空缺
- 自动带入当天上一条记录；提供「沿用昨日」「沿用上次」一键填充
- 支持 ±0.1 步进、键盘输入；按所选时段分别修改或删除
- 首页七格（4 + 3 两行）可直接点击任一空位补记

### 可视化

- **七次对比**：七条固定色系折线，同一日期维度上平行展示 7 个时段；点击图例可单独隐藏/显示时段
- **触摸查询**：按在图上可查看该日七个时段的数值与日均
- **日均曲线**：每日均值单线 + 7 日均线，支持 7 / 30 / 90 天与全部区间
- 每周变化柱状图（按周日均对比）
- 首页目标进度环、近 7 天日均迷你趋势
- 月度热力图：颜色映射日均高低，透明度映射当天记录完成度
- 时段均值对比条：近 30 天七个时段的平均体重
- 记录页七时段小圆点：一眼看出当天哪些时段已记录

### 分析

- 每日均值、区间最低/最高/平均、累计变化
- 周环比（自然周，周一为起点）
- 趋势速度：近 30 天日均线性回归，输出 kg/周 与 R²
- 目标预计达成日期、目标进度与剩余距离
- 日间波动 σ、日内极差（同一天 max−min 的平均）
- 餐前 / 餐后差值：自动找出差值最大的一餐
- 记录完整度：近 7 天完成次数 / 49，今日 x / 7
- BMI（依据最新日均与设置身高，采用中国成人标准分档）
- 基于以上指标的动态建议

### 数据管理

- 本地 JSON 存储，原子写入（临时文件 + 重命名）
- 设置页可导出 / 导入 JSON 备份，或清空全部记录
- 旧版本（每天一条、无时段字段）自动迁移为「第 1 次 · 早餐前」

## 七时段定义

| 序号 | 时段 | slot |
| --- | --- | --- |
| 1 | 早餐前 | 0 |
| 2 | 早餐后 | 1 |
| 3 | 午餐前 | 2 |
| 4 | 午餐后 | 3 |
| 5 | 晚餐前 | 4 |
| 6 | 晚餐后 | 5 |
| 7 | 睡前 | 6 |

每天每个时段最多一条记录；同一天允许少于 7 条，日均按**已记录时段**求平均。

---

## 指标口径

| 指标 | 计算方式 |
| --- | --- |
| 每日均值（日均） | 当天所有已记录时段的算术平均 |
| 周日均 | 该自然周（周一至周日）内有记录日期的日均之平均 |
| 趋势速度 | 近 30 天日均对日期做最小二乘回归；不足 3 天时使用全部数据 |
| R² | 回归拟合优度，0–1，越接近 1 表示日均变化越稳定 |
| 日间波动 σ | 近 30 天中相邻两天日均差值的样本标准差（至少 2 个差值） |
| 日内极差 | 同一天 max−min；展示近 30 天的平均值 |
| 餐前餐后差值 | 同一餐“餐后 − 餐前”，仅统计两者都存在的日期 |
| 时段均值 | 近 30 天内该时段所有记录的算术平均 |
| 记录完整度 | 近 7 天（含今天）记录条数 / 49；今日条数 / 7 |
| 目标预计 | 按近 30 天回归斜率线性外推至目标体重 |
| BMI | 最新日均 / (身高 m)²；<18.5 偏瘦，18.5–23.9 正常，24–27.9 超重，≥28 肥胖 |

> 日均与时段均值都在“近 30 天”窗口内计算；分析页会明确标注窗口。

## 技术实现

### 架构

- 单个 Activity 承载 4 个页面（今日 / 趋势 / 分析 / 记录），自绘底部导航切换
- 数据层 `WeightStore` 单例，内存列表 + 本地 JSON 落盘
- 统计引擎 `Stats` 在每次页面刷新时一次性计算所有指标
- 图表全部为自定义 `View`，使用 `Canvas` / `Path` / `LinearGradient` / `DashPathEffect`

### 主要图表组件

| 组件 | 用途 |
| --- | --- |
| `LineChartView` | 日均曲线：平滑曲线、渐变面积、7 日均线、目标线、触摸提示 |
| `MultiLineChartView` | 七时段平行折线：图例筛选、触摸多行提示、日均参考线 |
| `WeeklyBarChartView` | 每周日均变化柱状图 |
| `HeatmapView` | 月度热力图：颜色=日均，透明度=完成度 |
| `SlotAverageChartView` | 七时段近 30 天均值横向对比 |
| `SlotDotsView` | 记录页当天七时段记录状态圆点 |
| `RingProgressView` | 首页目标进度环 |
| `SparklineView` | 首页近 7 天日均迷你趋势 |

### 存储

数据文件位于应用内部存储：`/data/data/com.weightdiary/files/records.json`

```json
{
  "version": 2,
  "app": "weight-diary",
  "records": [
    { "date": "2026-10-31", "slot": 0, "weight": 73.6 },
    { "date": "2026-10-31", "slot": 1, "weight": 74.6 },
    { "date": "2026-10-31", "slot": 2, "weight": 74.0 },
    { "date": "2026-10-31", "slot": 3, "weight": 74.8 }
  ]
}
```

- `slot` 缺省时按 0（早餐前）处理，兼容 v1.0 的单条记录格式
- 写入采用 `.tmp` + `renameTo`，尽量避免异常退出造成文件损坏

## 构建

项目不使用 Gradle，`build.ps1` 直接调用 Android SDK 命令行工具完成打包，便于在无 Android Studio 的环境下出包。

### 环境要求

- Windows + PowerShell
- JDK 17 及以上（脚本当前指向 `C:\Program Files\Java\jdk-23`，可按需修改）
- Android SDK 组件：
  - Build-Tools（脚本使用 35.0.1，需包含 `aapt2`、`d8`、`zipalign`、`apksigner`、`core-lambda-stubs.jar`）
  - Platform `android-35`（提供 `android.jar`）

目录约定（`build.ps1` 顶部可改）：

```
.build/ext/
├── android-15/          # Build-Tools 压缩包解压后的根目录（此处沿用压缩包内目录名）
└── android-35/
    └── android.jar      # Platform android-35
```

### 打包

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

流程：

1. `aapt2 compile` 编译资源 → `aapt2 link` 生成基础 APK 与 `R.java`
2. `javac`（`-source 1.8`，`bootclasspath` 指向 `android.jar` + lambda stubs）
3. `d8 --min-api 26` 生成 `classes.dex`
4. 将 dex 写入 APK → `zipalign` → `apksigner` 签名
5. 输出：`WeightDiary-v1.4.apk`

> 首次构建会在 `.build/debug.keystore` 自动生成调试签名（口令 `android`）。如需发布，请替换为自己的正式签名，并同步调整 `versionCode` / `versionName`（位于 `app/AndroidManifest.xml`）。

### 安装

将 APK 传到手机，允许“安装未知来源应用”后安装。覆盖安装会保留本地数据。

## 隐私

- 无网络权限、不申请任何敏感权限
- 数据只写入应用私有目录，不参与云同步
- 导出备份由用户主动通过系统文件选择器完成
- 卸载应用会同时删除本地数据，换机前请先导出

## 已知限制

- 应用锁定竖屏，面向手机单手使用
- 七个时段固定，不支持自定义时段
- 无云同步、桌面小组件与提醒通知
- 当前使用本地调试签名，不适用于直接上架应用商店
